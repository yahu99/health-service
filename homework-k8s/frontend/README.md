# Локальный фронтенд Saga Store

Простой интерфейс к существующему BFF: регистрация и вход, каталог и остатки,
слоты доставки, баланс, создание и поиск заказа, шаги Saga, повтор запроса,
профиль и журнал HTTP-запросов. Все действия выполняются вручную
через формы сайта.

Нужен **Node.js 20+**. Внешних npm-зависимостей и этапа сборки нет.
Приложение работает локально, публикация и сторонние сервисы не используются.

## Запуск

Сначала запустите бэкэнд по инструкции `../../homework-9/README.md`.
В `/etc/hosts` должна быть запись `127.0.0.1 arch.homework`.

В первом терминале:

```bash
kubectl -n yahu port-forward service/nginx-ingress-nginx-controller 8081:80
```

Во втором терминале, из каталога `homework-k8s/frontend`:

```bash
npm start
```

Откройте **http://127.0.0.1:5173**. Войдите в существующий аккаунт или
зарегистрируйтесь через интерфейс. Не чередуйте `localhost` и `127.0.0.1`:
cookie и история браузера привязаны к адресу.

Другой адрес Gateway или порт фронтенда:

```bash
API_BASE_URL=http://arch.homework:8081 PORT=5174 npm start
```

`API_BASE_URL` — origin Ingress без пути. Используйте Ingress, поскольку он
проверяет сессию и выставляет доверенный `X-User-Id`; прямой адрес BFF не подходит.

Остановка — `Ctrl+C` в обоих терминалах.
